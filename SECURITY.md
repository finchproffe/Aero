# Security policy

Aero is pre-alpha and has not completed a security audit. Do not use it for banking, password storage, cryptocurrency wallets, or other high-risk activity.

Before public release, the repository owner must:

- enable GitHub private vulnerability reporting;
- define a monitored security contact;
- publish supported versions and response expectations;
- establish a signed release process;
- document update verification and rollback behavior.

Until a private reporting channel is configured, do not publish proof-of-concept exploits or private user data in public issues.
